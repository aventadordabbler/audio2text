# Audio2Text 会议助手用户操作手册

本文以 **客户端进行会议录音** 为主。Web 端用于管理员配置会议服务和模型，不作为日常会议录音入口。部署人员请先阅读[部署手册](deployment.md)；本文假定会议服务已经启动并可以访问。

## 1. 功能和使用边界

Audio2Text 提供以下能力：

- 客户端采集麦克风并实时转写；
- 录音的开始、暂停、继续和结束；
- 会后说话人校正；
- 根据完整转写生成结构化会议纪要；
- 客户端按会议阶段显示阶段总结；
- 会议、部门和历史记录管理；
- 导出转写文本、Markdown 纪要和 WAV 录音。

使用分工如下：

| 入口 | 用途 |
| --- | --- |
| 客户端 | 创建会议、录音、查看实时转写、暂停/继续/结束、查看总结和导出文件 |
| Web 端 | 配置 ASR、大语言模型和服务参数，供管理员使用 |
| 会议服务端 | 保存录音、转写、会议元数据、模型配置和纪要，执行后台处理 |

## 2. 首次使用准备

### 2.1 管理员：通过 Web 端配置模型

打开管理员提供的 Web 地址，进入左侧“模型配置”。Web 端只承担配置工作，不用于日常录音。

在“ASR 模型”页填写：

- **API 地址**：会议服务端可以访问的 OpenAI 兼容 API 基础地址，通常以 `/v1` 结尾；
- **模型名称**：模型服务实际提供的模型 ID；
- **识别方式**：
  - **Qwen 前缀续写**：适用于支持音频对话和 assistant 前缀续写的 Qwen/vLLM 服务；
  - **文件转写（兼容模式）**：适用于只提供标准 `/audio/transcriptions` 接口的服务；
- **API Key**：需要鉴权时填写，无鉴权的内网服务可以留空；
- **请求超时（秒）**：允许范围为 1–600 秒。

点击“测试连通性”，确认成功后点击“保存配置”。已有密钥时，API Key 留空会保留原密钥；需要删除密钥时勾选“清除已保存的密钥”。

切换到“大语言模型”页，填写 API 地址、模型名称、API Key 和请求超时，同样执行测试和保存。实时转写需要 ASR 配置；会议纪要和阶段总结需要大语言模型配置。

配置由会议服务端保存。修改配置不会影响已经开始的录音或正在执行的任务，新录音和新纪要任务使用新配置。

### 2.2 用户：配置客户端

1. 启动“会议助手”客户端。
2. 点击左侧“模型设置”。
3. 在“语音转写”页填写会议服务地址，例如 `http://127.0.0.1:8000`，选择默认识别语言，然后点击“测试连接”。
4. 使用“麦克风电平测试”确认系统能够采集声音。
5. 在“大语言模型”页确认服务端模型配置已加载；需要修改时填写接口地址、模型名称、接口密钥和请求超时，点击“测试连接”，再点击右上角“保存配置”。

首次录音前，请在操作系统中允许 客户端使用麦克风。

## 3. 使用客户端录音

### 3.1 管理部门

1. 点击左侧“部门管理”。
2. 点击“新增部门”，输入名称并点击“保存部门”。
3. 点击编辑按钮可以重命名部门，关联会议会同步显示新名称。
4. 没有关联会议的部门才可以删除；已有会议的部门不能直接删除。

部门用于创建会议时分类，并帮助后续筛选历史记录。

### 3.2 创建会议

1. 进入“会议管理”，点击“新建会议”。
2. 输入会议名称，最多 80 个字符。
3. 选择所属部门，或选择“未分类”。
4. 点击“创建并进入”。

创建会议不会立即打开麦克风。进入会议工作台后，点击“开始会议”才会开始采集声音。

### 3.3 开始、暂停、继续和结束

1. 点击“开始会议”。如果系统弹出麦克风权限提示，请选择允许。
2. 说话时，文字会持续显示在“实时转写”页。识别中的临时文字可能被修订，已定稿文字会自动保存。
3. 需要暂时停止采集时点击“暂停”。暂停期间不会录音，已有内容会保留。
4. 需要继续时点击“继续”，系统会在同一会议中接着记录。
5. 会议结束时点击“结束会议”，等待状态栏提示内容已保存。

结束操作会先处理最后一段音频，再保存转写并启动会后任务。若连接短暂中断，已保存的录音和定稿文字会保留；重新打开会议后可以继续录音。页面显示“重试结束会议”时，再次点击该按钮完成封口。

关闭客户端窗口时会弹出选择框：

- **最小化窗口**：让会议继续运行；
- **关闭窗口**：停止当前录音；
- **取消**：返回会议工作台。

### 3.4 查看实时转写和阶段总结

在“实时转写”页可以：

- 使用“自动跟随”开关控制是否滚动到最新文字；
- 查看每段文字的时间和说话人状态；
- 复制全部转写文本；
- 查看 ASR 运行诊断，了解识别模式、请求耗时和待处理积压。

客户端会在转写区显示阶段总结气泡。气泡显示生成时间范围和阶段摘要，内容过长时可以展开全文。生成失败时点击“重试”。阶段总结用于快速浏览，正式引用内容时请以完整转写和会议总结为准。

说话人标签可能暂时显示“说话人待确认”“多人同时讲话”或“多位说话人”，这不影响文字保存。

## 4. 会后处理和会议总结

### 4.1 说话人校正

结束会议后，服务端会在后台校正说话人。常见状态如下：

| 状态 | 含义 |
| --- | --- |
| 说话人标注中 / 等待校正 | 任务尚未开始或正在排队 |
| 正在校正说话人 | 正在处理录音 |
| 说话人校正已完成 | 转写中的说话人标签已更新 |
| 说话人校正未完成 | 任务失败，可以重试 |
| 说话人识别未就绪 | 未安装或未配置说话人模型 |

说话人服务不可用时，原始转写仍然可用。显示“重试说话人校正”时点击该按钮重新提交任务。

### 4.2 生成和查看会议总结

1. 结束会议并等待转写保存；说话人校正进行中时先等待校正完成。
2. 切换到“会议总结”页。
3. 页面自动生成总结时会显示“正在生成总结”，任务在离开页面后仍会继续。
4. 如果没有自动生成，点击“生成总结”。
5. 生成完成后阅读 Markdown 格式内容，通常包含会议主题、核心结论、决策事项、待办事项、风险和下一步安排。
6. 转写更新后页面会提示“转写已更新，可重新生成纪要”，点击“重新生成”获取最新版本。
7. 生成失败时点击“重试生成”，若提示模型未配置，请联系管理员在 Web 端完成大语言模型配置。

会议总结由模型根据转写整理生成。涉及责任人、日期、金额等关键信息时，应结合原始转写人工核对。

## 5. 查询和打开历史会议

在 客户端的“会议管理”页可以按以下条件筛选：

- 会议名称；
- 所属部门，包括“未分类”；
- 会议状态：未开始、录音中、已暂停、已结束；
- 创建日期范围。

点击“重置筛选”清除条件，点击“刷新列表”重新读取服务端记录。点击会议名称可以打开详情；左侧“最近会议”也可以快速打开最近记录。

## 6. 下载和导出

在会议工作台或历史会议详情中可以使用：

- **下载转写文本**：下载 `.txt` 文件；
- **导出录音（WAV）**：下载服务端已归档的整场录音；
- **生成总结后打开独立窗口**：在单独窗口阅读会议总结。

录音导出按钮只在服务端存在有效录音归档时显示。会议总结尚未生成时不会提供总结内容。

## 7. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 点击“开始会议”后没有声音 | 检查操作系统麦克风权限；运行“麦克风电平测试”；确认麦克风没有被其他程序独占。 |
| 客户端无法连接会议服务 | 检查“模型设置”中的会议服务地址、端口和网络；确认服务端健康检查正常。 |
| ASR 测试失败 | 请管理员在 Web 端检查 API 地址、模型名称和 API Key；兼容模式需要标准音频转写接口，Qwen 模式需要前缀续写能力。 |
| 实时转写出现延迟 | 查看运行诊断中的待处理积压，等待服务恢复；不要重复创建会议。 |
| 说话人一直未就绪 | 不影响文字转写；请管理员安装并配置本地说话人模型后重试校正。 |
| 会议总结不可用 | 确认会议已结束且存在转写；请管理员检查 Web 端大语言模型配置和连通性，再点击“重试生成”。 |
| 会议突然变成已暂停 | 可能是 WebSocket 断开或客户端暂时离线。重新打开会议，确认已有内容后点击“继续”。 |
| 关闭窗口后录音停止 | 关闭窗口会停止录音；需要继续录音时选择“最小化窗口”。 |
| WAV 导出失败 | 确认会议确实产生了录音；仍失败时请管理员检查服务端 `data` 目录和录音清单。 |

## 8. 数据和隐私提示

- API Key、录音、转写和会议总结由会议服务端保存，请限制服务端数据目录的访问权限。
- 录音结束前不要删除或移动服务端数据目录。
- 模型生成的转写和总结可能存在识别错误，正式对外发送前请人工复核。

## 9. 状态速查

| 状态 | 说明 | 可执行操作 |
| --- | --- | --- |
| 未开始 | 会议已创建，尚未录音 | 开始会议、结束会议 |
| 录音中 | 正在采集麦克风并转写 | 暂停、结束会议 |
| 已暂停 | 录音已暂停，内容已保留 | 继续、结束会议 |
| 已结束 | 录音已封口 | 查看转写、说话人校正、生成总结、下载文件 |
