# 会议工具用户使用手册

> 本手册从会议参与者、会议组织者和管理员的使用角度编写。文中使用的系统名称统一为“会议工具”。
>
> 可打印版本：[会议工具用户使用手册.docx](meeting-tool-manual/会议工具用户使用手册.docx)

## 1. 系统使用场景与功能组成

### 1.1 使用场景

会议工具用于把一次会议从“开始讨论”整理到“留下可执行记录”。常见使用方式如下：

- **现场会议**：打开会议工具，选择麦克风并开始录音；讨论内容会同步形成文字，会议结束后可以查看说话人、阶段总结和会议纪要。
- **远程或混合会议**：将会议工具放在能听到会议声音的位置，使用同样的录音、暂停和结束流程，参与者无需改变发言习惯。
- **已有录音整理**：会议已经结束时，可以导入 WAV 或 MP3 音频，让会议工具在后台整理转写、说话人标注和会议纪要。
- **会后复盘**：通过历史会议搜索特定会议，阅读完整转写，核对结论和待办，并导出文本、纪要或录音。
- **团队分类管理**：通过部门给会议分类，按部门、状态、日期和名称快速找到需要的记录。

### 1.2 功能组成

| 功能 | 作用 | 主要使用者 |
| --- | --- | --- |
| 模型设置 | 设置语音转写和会议纪要所需的服务，并测试是否可用 | 管理员 |
| 部门管理 | 建立会议所属部门，便于分类、筛选和统计 | 管理员、会议组织者 |
| 新建会议 | 创建实时录音会议或导入已有 WAV/MP3 音频 | 会议组织者 |
| 实时录音 | 开始、暂停、继续和结束一次会议 | 会议参与者 |
| 实时转写 | 查看正在形成的会议文字，并回看已保存内容 | 会议参与者 |
| 阶段总结 | 按讨论阶段快速查看重点，并跳转回对应内容 | 会议参与者 |
| 说话人标注 | 在会后为转写内容补充会议内的说话人标签 | 会议组织者 |
| 会议纪要 | 将完整转写整理为结论、决策、待办、风险和下一步 | 会议组织者 |
| WAV/MP3 导入 | 对已有录音进行后台整理，并支持失败后重试 | 会议组织者 |
| 历史会议 | 搜索、筛选和重新打开已保存的会议 | 所有用户 |
| 文件导出 | 导出转写文本、完整录音和会议纪要 | 所有用户 |

### 1.3 一次会议的完整流程

1. 管理员完成模型设置；会议组织者按需要维护部门。
2. 在“会议管理”中新建会议，填写名称并选择部门。
3. 进入会议工作台，确认麦克风状态后点击“开始会议”。
4. 讨论过程中查看实时转写和阶段总结，需要休息时点击“暂停”，回来后点击“继续”。
5. 讨论结束后点击“结束会议”，等待转写保存和会后整理完成。
6. 打开“会议纪要”阅读整理结果，必要时重新生成或人工核对。
7. 按需导出 TXT、WAV 或纪要文件，并在历史会议中保留后续复盘入口。

## 2. 使用前准备

### 2.1 选择使用入口

会议工具提供桌面端和浏览器端。两种入口都可以创建会议、录音、查看转写、导入 WAV/MP3 和导出文件；桌面端更适合长期放在会议现场，浏览器端适合临时访问或集中管理。

### 2.2 检查麦克风

首次进行实时录音前：

1. 打开“模型设置”。
2. 在语音转写设置中确认会议服务地址可用，并点击“测试连接”。
3. 在桌面端打开“麦克风输入测试”，确认音量指示会随声音变化。
4. 第一次点击“开始会议”时，如果系统询问麦克风权限，请选择允许。

### 2.3 选择识别语言

新建会议时可以选择识别语言。普通中文会议选择“中文”即可；包含多种语言时可以选择“自动检测语言”。语言选择会影响实时转写和导入音频的整理结果。

## 3. 模型设置

模型设置决定会议工具能否完成实时转写和会议纪要。只需要管理员在首次使用前配置，普通参会者不需要重复修改。

![模型设置页面：语音转写和大语言模型分别配置](meeting-tool-manual/screenshots/model-settings.png)

*图 1　模型设置页面*

### 3.1 配置语音转写

1. 点击左侧“模型设置”。
2. 选择“语音转写”页签。
3. 填写“接口地址”和“模型名称”。这些信息由系统管理员或服务提供方给出。
4. 根据服务能力选择识别方式：
   - **Qwen 前缀续写**：适合需要连续修订当前发言的服务。
   - **文件转写（兼容模式）**：适合标准音频转写服务。
5. 如果服务需要鉴权，填写“接口密钥”；不需要鉴权时可以留空。
6. 设置请求超时，点击“测试连接”，看到连接成功后点击“保存配置”。

### 3.2 配置会议纪要

1. 切换到“大语言模型”页签。
2. 填写接口地址、模型名称、接口密钥和请求超时。
3. 点击“测试连接”确认可以生成内容，再点击“保存配置”。

语音转写配置用于形成会议文字，大语言模型配置用于生成阶段总结和会议纪要。保存后，新开始的会议会使用新设置；已经在处理中的会议继续使用原来的设置。

## 4. 部门管理

部门用于给会议分类，也用于历史会议筛选。没有部门时可以选择“未分类”。

![部门管理页面：新增、编辑和删除部门](meeting-tool-manual/screenshots/departments.png)

*图 2　部门管理页面*

### 4.1 新增部门

1. 点击左侧“部门管理”。
2. 点击右上角“新增部门”。
3. 输入部门名称，点击“保存部门”。
4. 返回会议创建页面后，新部门会出现在“所属部门”选项中。

### 4.2 编辑部门

1. 在部门列表中找到目标部门。
2. 点击该行的编辑按钮。
3. 修改名称并点击“保存部门”。

修改名称不会改变已有会议的归属，历史会议会显示新的部门名称。

### 4.3 删除部门

1. 点击目标部门的删除按钮。
2. 在确认窗口中点击“确认删除”。

已经关联会议的部门不能删除；如需清理部门，请先确认不会影响历史记录的分类需求。

## 5. 新建会议与实时录音

### 5.1 新建实时录音会议

![新建会议弹窗：选择实时录音或导入已有 WAV/MP3](meeting-tool-manual/screenshots/create-meeting.png)

*图 3　新建会议弹窗*

1. 进入“会议管理”，点击“新建会议”。
2. 在“创建方式”中选择“实时录音”。
3. 输入会议名称，名称应能帮助后续搜索，例如“产品设计周会”。
4. 选择所属部门；不需要分类时选择“未分类”。
5. 点击“创建并进入”。创建会议不会马上打开麦克风。
6. 在会议工作台确认设备状态后，点击“开始会议”。

### 5.2 控制录音

![录音中的会议工作台：实时转写、录音控制和阶段总结](meeting-tool-manual/screenshots/recording-live.png)

*图 4　录音中的会议工作台*

- **开始会议**：开始采集声音并显示实时转写。
- **暂停**：暂时停止采集，已经保存的内容不会消失。
- **继续**：在同一场会议中接着录音。
- **结束会议**：停止本次录音，保存最后一段内容并进入会后整理。

结束前请确认最后一位发言人已经说完。点击“结束会议”后等待状态变为已结束，再关闭页面或应用。

### 5.3 录音时的注意事项

- 让麦克风尽量靠近主要发言人，避免扬声器回声和多人同时抢话。
- 如果转写暂时落后，先等待页面恢复，不要重复创建会议。
- 需要离开电脑时可以最小化窗口；不要直接关闭正在录音的窗口。

## 6. 实时转写

实时转写是会议工作台的主要内容区。识别中的文字可能会随着后续声音修订，已经保存的转写会持续保留。

![实时转写页面：查看发言文字、时间和说话人状态](meeting-tool-manual/screenshots/recording-live.png)

*图 5　实时转写页面*

### 6.1 查看和跟随文字

1. 在会议工作台保持“实时转写”页签打开。
2. 打开“自动滚动”时，页面会跟随最新发言。
3. 关闭“自动滚动”后可以自由回看前面的内容；需要回到末尾时点击“回到最新”。
4. 每段转写会显示时间和说话人状态。说话人尚未确定时，会显示“说话人待确认”。

### 6.2 复制当前转写

当会议已有转写内容时，点击转写区底部的复制按钮可以复制全部已保存文字。复制失败时可使用“导出文本（TXT）”。

### 6.3 处理暂时没有文字的情况

如果会议刚开始，转写区会先显示等待提示；如果整场会议没有检测到有效语音，结束后会显示暂无转写内容。请先检查麦克风测试和系统权限，再决定是否重新录制。

## 7. 阶段总结

阶段总结位于会议工作台右侧，用于快速了解一段讨论的重点。它适合在会议过程中浏览，不替代完整转写。

![阶段总结区域：查看阶段重点并跳转到原文](meeting-tool-manual/screenshots/stage-summary.png)

*图 5　阶段总结区域*

### 7.1 查看阶段总结

1. 保持会议处于录音或会后整理状态。
2. 在右侧“阶段总结”区域查看按时间形成的总结卡片。
3. 卡片内容较长时点击“展开全文”；再次点击“收起”恢复简要视图。
4. 点击“查看原文”可以回到该阶段对应的转写位置。

### 7.2 阶段总结失败时重试

总结卡片显示失败提示时，点击卡片中的“重试”。重试期间可以继续查看完整转写；阶段总结不会影响录音保存。

## 8. 说话人标注与校正

会议工具会在会后尝试为转写内容补充会议内的说话人标签。标签是本场会议中的匿名身份，用于区分不同发言，不代表实名识别。

![会议工作台中的说话人处理状态](meeting-tool-manual/screenshots/stage-summary.png)

*图 6　说话人处理状态*

### 8.1 查看处理状态

会议详情顶部和转写区底部会显示处理状态：

| 页面提示 | 说明 |
| --- | --- |
| 说话人标注中 | 已提交处理，正在等待开始 |
| 正在校正说话人 | 正在整理发言人标签 |
| 说话人已完成 | 标签已经写入转写记录 |
| 说话人校正未完成 | 本次处理失败，可以重试 |
| 说话人识别未就绪 | 当前环境没有可用的说话人能力，文字转写仍然保留 |

### 8.2 重试说话人校正

1. 等会议状态变为“已结束”。
2. 在转写区底部找到“重试说话人校正”。
3. 点击按钮并等待状态刷新。

说话人处理失败不会删除转写或阻止导出。多人同时讲话时，页面可能显示“多人同时讲话”或“多位说话人”，正式引用发言人信息前请人工核对原始录音。

## 9. 会议纪要

会议纪要根据已保存的完整转写整理，通常包含核心结论、决策事项、待办事项、风险和下一步安排。

![独立会议总结窗口：查看整理后的结论和待办](meeting-tool-manual/screenshots/minutes-window.png)

*图 6　会议纪要阅读窗口*

### 9.1 生成会议纪要

1. 结束会议并等待转写保存；如果正在校正说话人，先等待校正完成。
2. 点击“会议纪要”页签。
3. 页面显示“生成纪要”时，点击该按钮。
4. 等状态显示“纪要已保存”后阅读内容。离开页面不会中断后台整理。

导入 WAV/MP3 的会议会在后台自动整理；打开详情页即可查看处理状态。

### 9.2 重新生成和核对

当转写发生变化，页面会提示“转写已更新，可重新生成纪要”。点击“重新生成”获取新版本。涉及负责人、日期、金额和承诺事项时，请回到“实时转写”逐条核对，不能只依赖自动整理结果。

### 9.3 阅读和单独打开

- 在会议工作台中直接阅读纪要。
- 点击复制按钮复制全部纪要。
- 点击“下载纪要”保存文件。
- 点击“独立窗口”在单独窗口中阅读，适合会议复盘或分享屏幕。

## 10. 导入已有 WAV/MP3 音频

导入适合整理已经结束的录音。导入过程中不需要打开麦克风，也不会占用实时录音控制。

![桌面端导入 WAV/MP3 后的会议详情：显示导入完成、转写和纪要](meeting-tool-manual/screenshots/wav-import-client.png)

*图 7　桌面端 WAV/MP3 导入结果*

![浏览器端导入 WAV/MP3 后的会议详情：显示转写、纪要和下载入口](meeting-tool-manual/screenshots/wav-import-web.png)

*图 8　浏览器端 WAV/MP3 导入结果*

### 10.1 上传和处理

1. 在“会议管理”中点击“新建会议”。
2. 将“创建方式”切换为“导入音频（WAV/MP3）”。
3. 选择要整理的 WAV 或 MP3 文件。
4. 填写会议名称、所属部门和识别语言。
5. 点击“上传并创建”。
6. 等待详情页显示导入、转写、说话人处理和纪要状态；上传完成后可以离开页面，后台会继续处理。

导入会议在历史列表中显示为已结束，但详情页会额外显示导入处理状态。会议时长以音频内容为准，静音部分也会计入时长。

### 10.2 失败后重试

1. 在详情页查看导入状态和失败提示。
2. 点击“重试处理”。
3. 等待状态回到处理中，完成后重新打开“实时转写”和“会议纪要”。

重试会沿用已经上传的音频；如果只有纪要失败，系统会保留已有转写并重新整理纪要。正在处理的导入会议完成前不要删除。

## 11. 历史会议与筛选

![会议管理页面：按名称、部门、状态和日期筛选会议](meeting-tool-manual/screenshots/meeting-management.png)

*图 9　会议管理和历史会议列表*

### 11.1 搜索和筛选

1. 点击左侧“会议管理”。
2. 在搜索框输入会议名称关键词。
3. 选择所属部门和会议状态。
4. 选择创建开始日期和结束日期。
5. 点击“刷新列表”获取最新记录。
6. 点击“重置筛选”恢复完整列表。

筛选条件可以组合使用。会议状态包括“未开始”“录音中”“已暂停”和“已结束”。

### 11.2 打开历史会议

点击列表中的会议名称即可进入详情。详情页会保留转写、说话人状态、阶段总结、会议纪要和文件导出入口。左侧“最近会议”也可以快速打开最近访问的记录。

## 12. 文件导出

会议详情页顶部提供导出入口：

![会议详情页中的文本和录音导出入口](meeting-tool-manual/screenshots/wav-import-client.png)

*图 10　文件导出入口*

### 12.1 导出转写文本

1. 打开目标会议详情。
2. 点击“导出文本（TXT）”。
3. 在保存位置确认文件名，文件内容为点击时已经保存的完整转写。

导出的文本不包含仍在变化的临时识别内容，也不包含会议纪要。实时录音中、暂停后和结束后都可以导出已有内容。

### 12.2 导出录音

1. 确认会议详情页显示“导出录音（WAV）”。
2. 点击按钮并等待文件准备完成。
3. 在保存位置确认录音文件可正常播放。

只有存在有效录音的会议才会显示录音导出按钮。

### 12.3 下载会议纪要

在“会议纪要”页签底部点击“下载纪要”。下载的是最近一次保存的纪要版本；如页面提示转写已更新，请先重新生成再下载。

## 13. 窗口关闭与录音保护

关闭正在录音的窗口前，会议工具会显示确认窗口。

![关闭窗口确认：最小化可以让会议继续](meeting-tool-manual/screenshots/close-confirmation.png)

*图 10　关闭窗口确认*

- **最小化窗口**：保留会议运行，让录音继续。
- **关闭窗口**：停止当前录音并关闭窗口。
- **取消**：返回会议工作台。

如果录音因窗口关闭或网络短暂中断而进入“已暂停”，重新打开该会议并点击“继续”即可接着记录。已有转写和录音内容会保留。

## 14. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 点击开始会议后没有声音 | 检查系统麦克风权限，运行“麦克风输入测试”，确认麦克风没有被其他程序占用。 |
| 会议无法开始 | 在“模型设置”中测试语音转写连接，确认服务地址和模型名称填写正确。 |
| 实时文字暂时落后 | 等待页面恢复并观察是否继续增长，不要重复创建会议；结束前确认最后内容已保存。 |
| 说话人一直待确认 | 文字转写不受影响；结束会议后等待处理，仍失败时点击“重试说话人校正”。 |
| 阶段总结失败 | 点击该阶段卡片中的“重试”；完整转写仍然可以查看。 |
| 会议纪要无法生成 | 确认会议已结束且有转写，在“模型设置”中测试大语言模型连接后重试。 |
| WAV/MP3 导入失败 | 确认选择的是可播放的 WAV 或 MP3 文件，查看详情页提示并点击“重试处理”。 |
| 找不到历史会议 | 点击“重置筛选”，再按名称、部门和日期逐步缩小范围。 |
| 关闭窗口后录音停止 | 关闭窗口会停止录音；需要继续时请选择“最小化窗口”，或重新打开会议后点击“继续”。 |

## 15. 状态速查

| 状态 | 含义 | 可以做什么 |
| --- | --- | --- |
| 未开始 | 会议已创建但还没有录音 | 开始会议、结束会议 |
| 录音中 | 正在采集声音并形成转写 | 暂停、结束会议、查看实时转写 |
| 已暂停 | 录音暂时停止，已有内容已保留 | 继续、结束会议、查看和导出已有内容 |
| 已结束 | 本次录音已经封口 | 查看转写、等待说话人处理、生成纪要、导出文件 |
| 导入处理中 | WAV/MP3 正在后台整理 | 查看进度、离开页面、失败后重试 |
| 纪要已保存 | 会议纪要已经生成 | 阅读、复制、下载或重新生成 |

## 16. 使用建议

- 会议开始前先做一次麦克风测试，并确认会议名称和部门正确。
- 重要结论和待办事项以完整转写为依据，自动生成的阶段总结和纪要用于提高整理速度，发送前请人工复核。
- 会议结束后等待状态稳定为“已结束”再退出应用或清理设备。
- 需要长期留存时，同时保存 TXT 转写、会议纪要和 WAV 录音，方便后续核对。
